Esta carpeta conserva assets **pendientes de autorización o de rol público**.

**No** marcar como `published` en `lib/content/partners.ts` o `people.ts` sin confirmación escrita.

Cuando se autorice un asset:

1. Confirmar categoría, link y permiso de uso.
2. Mover o copiar a la ruta de producción acordada.
3. Actualizar el registro de contenido con `status: "published"`.
4. Retirar o archivar la copia de staging.
