# Art Direction — SIGNAL SYSTEM

## Idea

> Una señal que conecta **retos**, **talento** y **resultados**.

El website no compite por más glow: compite por una gramática visual propia y reconocible sin logo.

## Motivos

| Motivo | Función |
|--------|---------|
| Signal Rail | Línea narrativa que une secciones / días / progreso |
| Nodos | Momentos de decisión: tracks, checkpoints, entregables |
| Spark | Energía puntual (uso restringido) |
| Códigos HT GT FT TNBT | Identidad de track sin depender solo del color |
| Progreso | descubrir → postular → preparar → construir → presentar → continuar |
| Conexiones | ToB → talento → industria → soluciones |

## Texturas por track

- **HealthTrack** — pulso, señal, curvas, datos vitales
- **GreenTrack** — topografía, ondas orgánicas, redes territoriales
- **FinTrack** — flujos, nodos transaccionales, matrices
- **The Next Big Thing** — órbitas, expansión, geometría experimental

## Fotografía

Personas reales, equipos trabajando, pizarras, prototipos, escenario Demo Day. Ángulos documentales; luz azul con acentos cálidos (Spark).

## Prohibido

Hackers encapuchados · código Matrix · cerebros digitales · manos robóticas · ciudades futuristas stock · laptops flotantes · 3D infantil · glassmorphism masivo · blobs · gradientes arcoíris · dashboards falsos · grids de cards idénticos consecutivos

## Composición

- Asimetría editorial > centrado genérico
- Una idea visual dominante por sección
- Espacio negativo generoso
- Tipografía: Syne + DM Sans (no migrar sin aprobación)
