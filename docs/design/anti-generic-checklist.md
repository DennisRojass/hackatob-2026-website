# Anti-Generic Checklist

Usar antes de mergear un rediseño de sección.

## Composición

- [ ] La sección tiene una composición propia
- [ ] No repite el grid de la sección anterior
- [ ] Hay una idea visual dominante (rail, nodo, dossier, escalera, foto…)
- [ ] El diseño comunica función, no solo decoración
- [ ] Espacio negativo suficiente
- [ ] Jerarquía editorial clara (display → body → meta)

## Efectos

- [ ] No depende de glow para “verse premium”
- [ ] No depende de glassmorphism masivo
- [ ] No parece dashboard SaaS / crypto / gamer
- [ ] Máx. 3 ambientales animados en viewport
- [ ] Motion explica algo (o está apagado)

## Contenido

- [ ] Contenido real / published / fallback honesto
- [ ] Sin avatares fake ni logos draft
- [ ] Sin copy vacío (“transforma el futuro”…)
- [ ] Cifras alineadas a `config/event.ts`

## Responsive / a11y

- [ ] Móvil pensado, no comprimido
- [ ] Sin overflow en 390
- [ ] Foco visible; teclado OK
- [ ] Reduced motion OK

## Test de marca

- [ ] La sección podría reconocerse como HackaToB **sin leer el logo** (Signal System)

Si fallan 3+ ítems de composición/efectos → no declarar “listo”; iterar blueprint.
