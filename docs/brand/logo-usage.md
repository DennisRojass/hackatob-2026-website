# Logo Usage — HackaToB 2026

## Assets canónicos

| Asset | Ruta típica | Uso |
|-------|-------------|-----|
| Logo HackaToB | `/brand/hackatob-logo.svg` (+ PNG si existe) | Header, footer, OG |
| Spark | `/brand/spark.svg` | Hero, CTA final, confirmación |
| ToB isotipo | `/brand/tob-isotipo.svg` | Trust, footer |
| TEC | `/brand/tec-logo.svg` | Trust, footer |

Preferir **SVG** para UI. PNG solo si el archivo oficial lo requiere y no hay 404.

## Clear space y tamaño

- Mantener área libre ≈ altura de la “H” / Spark alrededor del logo
- Header: logo legible ≥ ~28–32 px de alto en móvil
- No estirar; no rotar; no recolorar fuera de variantes aprobadas
- No colocar el logo sobre fondos de bajo contraste sin placa

## Combinaciones

- **HackaToB solo** — nav principal del producto
- **HackaToB + Powered by ToB** — hero / pie de marca
- **ToB + TEC** — bloque de confianza institucional (línea, no cloud genérico)
- Aliados — jerarquía por categoría; nunca al mismo nivel que HackaToB/ToB sin autorización

## Spark — cuándo sí / no

**Sí:** Hero (idle), éxito de interés/postulación (celebrate), CTA final (point), Demo Day espera (waiting).

**No:** cada sección, rúbrica/jurado, errores, pitch, spam de hover.

## Prohibiciones

- Sombras neon excesivas / órbitas que compitan con el isotipo
- Mezclar versiones no oficiales (brackets distintos, Spark “cute” 3D infantil)
- Usar logos de sponsors `draft` como si fueran oficiales
- Inventar wordmarks (“HackaToB AI”, etc.)
