# Visual Checklist

Revisión Browser obligatoria en **1440 · 1280 · 768 · 390**.

## Global

- [ ] Sin scroll horizontal
- [ ] Fondos y tipografía coherentes (Syne / DM Sans)
- [ ] Skip link operable
- [ ] Announcement no pelea al Hero en móvil
- [ ] Header sticky usable; menú móvil OK

## Hero

- [ ] H1 completo visible (“Cuatro días. Cuatro áreas.”)
- [ ] Subtítulo sin clip
- [ ] CTAs usables
- [ ] Spark no tapa texto
- [ ] Métricas no saturan el primer viewport

## Secciones marketing

- [ ] No más de dos card-grids consecutivos evidentes
- [ ] Tracks distinguibles (código + color)
- [ ] Retos / aliados / comunidad honestos (sin fake)
- [ ] Agenda: un countdown
- [ ] CTA final = una acción

## Motion

- [ ] Ambientales ≤ 3 por vista
- [ ] Reduced motion: sin loop obligatorio
- [ ] Hover no es la única vía de info

## Marca

- [ ] Logos nítidos; cero 404
- [ ] Test: ¿parece HackaToB / Signal System, no SaaS genérico?

Registrar fallos con viewport + sección + severidad.
